개인정보처리방침

본 방침은 JWB STUDIO 웹사이트에서 외주 상담을 신청할 때 처리하는 개인정보에 관한 안내입니다. 실제 운영자의 연락처와 Supabase 프로젝트 리전·보관 설정을 반영해 공개 전에 내용을 확인해 주세요.

1. 처리하는 정보와 목적
이름(또는 기업명), 답변 이메일, 프로젝트 제목·내용, 이용자가 선택해 첨부한 참고 파일을 외주 상담 및 견적 안내 목적으로 처리합니다. 자동 등록 방지와 제출 제한을 위해 요청 시 IP 주소를 일방향 해시로 변환해 15분 단위 제한에 사용하며, 해당 값은 24시간이 지나면 정리됩니다. 별도의 회원가입은 제공하지 않습니다.

2. 보유 기간과 파기
상담 목적이 달성되면 지체 없이 파기합니다. 다만 분쟁 대응 또는 관련 법령에 보존 의무가 있는 경우 해당 기간 동안 별도 보관할 수 있습니다. 실제 운영 시 상담 종료 기준과 백업 데이터의 삭제 주기도 확인해 구체화해 주세요.

3. 처리 위탁 및 저장
문의 데이터와 선택 첨부파일은 사이트 운영자가 사용하는 Supabase 데이터베이스·스토리지에 저장됩니다. 자동 등록 방지를 위해 허니팟 입력란과 IP 기반 제출 횟수 제한을 적용합니다. 이메일 알림을 설정한 경우 Resend로 문의 내용이 운영자 이메일에 전달되며, Discord 알림은 개인정보를 포함하지 않은 새 문의 알림만 전송합니다. Supabase 프로젝트의 실제 리전, 각 서비스의 처리 위치와 보관 정책을 확인해 국외 이전 등 필요한 사항을 공개 전에 추가해 주세요.

4. 외부 콘텐츠
포트폴리오 작품을 재생할 때 YouTube 동영상이 임베드됩니다. 재생 시 YouTube/Google이 이용자의 접속 정보를 처리할 수 있으므로 해당 서비스의 개인정보 안내도 확인해 주세요.

5. 이용자 권리
이용자는 본인 정보의 열람, 정정, 삭제 또는 처리 정지를 요청할 수 있습니다. 문의 시 사용한 이메일로 요청해 주세요. 운영자 연락처: 연락 가능한 이메일을 js/contact-config.js 설정 후 이곳에도 기재

6. 보호 조치
관리자 인증과 데이터베이스 접근 정책을 적용하고, 문의 첨부파일은 비공개 저장소에 보관하도록 구성합니다.
