# 🎬 JWB STUDIO | Media & Motion Graphics Portfolio

> **"감각적인 컷 연출부터 인터랙티브 웹 연동까지."**  
> JWB STUDIO는 2D/3D 모션 그래픽, 비주얼 연출, 인터랙티브 미디어 웹을 제작하는 종합 비주얼 크리에이티브 스튜디오 포트폴리오 사이트입니다.

---

## 📌 주요 특징 (Key Features)

* **비디오 텍스트 마스킹 & 히어로 슬라이더**: HTML5 비디오 배경과 CSS `mix-blend-mode`를 활용한 브랜딩 마스킹 연출 및 자동 캐러셀 슬라이더[cite: 7]
* **다이나믹 테마 토글 (Dark / Light Mode)**: 사용자 설정 및 `localStorage` 기반 테마 상태 유지 기능 제공[cite: 7]
* **인터랙티브 포트폴리오 뷰어**: 
  * **뷰 모드 스위처**: 카드 그리드(Grid View) 및 리스트(List View) 전환 지원[cite: 7]
  * **세그먼트 필터링 & 실시간 검색**: 영상 편집, 3D, 모션, 웹 등 카테고리별 필터 및 키워드 검색 지원[cite: 7]
  * **YouTube 라이트박스 모달**: 작품 클릭 시 유튜브 상세 영상 및 프로젝트 메타 정보(제작 기간, 사용 툴) 팝업[cite: 7]
* **커스텀 마우스 커서 & 모션 효과**: 마우스 포인터 인터랙션, 스크롤 인터섹션 옵저버(Intersection Observer) 기반 페이드인 애니메이션[cite: 7]
* **반응형 웹 디자인**: 모바일 햄버거 메뉴 및 스마트폰/태블릿 최적화 레이아웃[cite: 7]

## 🛠 사용 기술 및 도구 (Tech Stack)

### Frontend & Web Development
* **HTML5 / CSS3**: Flexbox, CSS Grid, Custom Variables, Dynamic Themes, Keyframe Animations[cite: 7]
* **JavaScript (ES6+)**: DOM Manipulation, Intersection Observer API, Event Listeners[cite: 7]
* **FontAwesome**: UI 및 메타데이터 아이콘 라이브러리[cite: 7]

### Creative Software & Tools
* **Motion Graphics / Video**: Adobe After Effects, Premiere Pro[cite: 7]

* **Graphic Design**: Adobe Photoshop, Illustrator[cite: 7]
