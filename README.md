# 🎬 정원복 영상 편집자 & 모션 그래픽 디자이너 포트폴리오 웹사이트

감각적인 시선으로 가치 있는 영상을 제작하는 **영상 편집자 및 모션 그래픽 디자이너 정원복**의 개인 포트폴리오 웹사이트 프로젝트입니다.  
HTML5, CSS3, JavaScript(Vanilla JS)를 활용하여 웹 표준에 맞춰 제작되었으며, 시네마틱한 다크 무드 콘셉트와 사용자 친화적인 인터랙티브 UI/UX를 제공합니다.

---

## 📌 주요 기능 (Features)

### 1. 🎬 시네마틱 헤더 & 타이핑 애니메이션 (Intro)
- **타이핑 애니메이션 엔진**: 디자이너의 가치관과 정체성을 보여주는 인터랙티브 타이핑 텍스트 효과 제공 (`script.js`).
- **풀스크린 반응형 네비게이션**: 모바일 및 태블릿 화면을 위한 햄버거 메뉴 토글 지원.
- **커스텀 마우스 포인터**: 대화면 UI(Desktop) 환경을 고려한 붉은색 시네마틱 화살표 커스텀 커서 적용.

### 2. 🎥 포트폴리오 필터링 & 검색 (Portfolio)
- **카테고리 필터링**: `All`, `영상`, `광고`, `3D`, `포스터`, `타이틀시퀀스`, `인트로`, `상세페이지`, `모션` 등 세분화된 태그 필터.
- **실시간 검색**: 제목 및 키워드 기반 라이브 검색 기능.
- **상세보기 모달 (Modal Popup)**: YouTube 임베드 영상 및 고화질 이미지, 작업 기간, 사용 툴, 기여도 정보를 제공하는 모달 창 구현.

### 3. 💰 상품 안내 & 가격 정책 (Pricing)
- 프로젝트 규모(로고, Basic, Standard, Premium)에 따른 투명한 서비스 항목 및 단가 안내.

### 4. 🛠️ 스킬 & 프로그래밍 역량 (Skills)
- **영상/디자인 툴**: Premiere Pro, After Effects, Photoshop, Illustrator, Media Encoder, Blender
- **웹 개발 스킬**: HTML5, CSS3, JavaScript
- **시각화 그래프**: 스크롤 교차 시점(Intersection Observer)에 맞춰 자동으로 차오르는 스킬 프로그레스 바 적용.

### 5. 📢 관리자 기반 공지사항 시스템 (Notice)
- **로컬 스토리지 연동**: `localStorage`를 활용하여 공지사항 추가/수정/삭제 데이터 유지.
- **관리자 인증 기능**: 관리자 로그인 토글을 통해 새 공지 등록 및 실시간 인라인 편집/삭제 관리 권한 부여.
- **카테고리 탭**: 전체, 공지, 일정, 안내, 업데이트별 공지 분류.

### 6. ❓ 자주하는 질문 (FAQ Accordion)
- 제작 문의, 작업 절차, 수정 정책, 저작권 라이선스 관련 질문을 직관적인 아코디언 인터페이스로 제공.
